no mutations/network/dependencies/shared-file edits. Include these explicitly
in delegation; do not assume the parent conversation or repo rules transfer.

result. If not executed, write NOT RUN and identify who should run it.

**Handoff:** Files ready, lease released, next integration action; no automatic
push/PR/merge permission implied.
